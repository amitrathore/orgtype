# Orgtype

Static redesign of the Orgtype website for GitHub Pages.

The site is self-contained:

- `index.html` contains the page content.
- `styles.css` contains all layout and brand styling.
- `script.js` contains reduced-motion-aware scroll reveal behavior.
- `assets/images/` contains the downloaded image assets from the previous Carrd site.

## Local Preview

Open `index.html` directly in a browser, or run:

```sh
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
